# Shubh Mishra · Developer Portfolio

My personal portfolio: projects, skills, experience and contact, in one fast, responsive page.

**Live:** https://shubh-portfolio-henna.vercel.app

## Built with
- HTML5, Tailwind CSS (CDN), vanilla JavaScript
- Particles.js hero background and a typing-effect tagline
- Scroll-triggered fade-ins with the Intersection Observer API
- Deployed on Vercel

## Highlights
- Fully responsive with a mobile hamburger menu
- Project cards link to both the live demo and the source code
- Skills grouped as Frontend, Tools & Backend, and Design

## Run locally
```bash
git clone https://github.com/ShubhMishra44/Shubh-Portfolio.git
cd Shubh-Portfolio
# open index.html in your browser
```
